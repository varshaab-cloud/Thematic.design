# Retired token exports

Kept for reference, no longer maintained. Do not edit and do not consume.

These were the first generation of exports produced from `tokens.css` before the
`tokens 1.5/` set existed. They are superseded because:

- `tokens 1.5/tokens.json` is the same flat map, generated by the current exporter
- `tokens 1.5/tokens.dtcg.json` adds `$description` on every token and uses the
  1.4-compatible set structure; the copy here has neither
- `token-export.cjs` here wrote into `src/styles/`, which mixed generated files
  into the same folder as the hand-maintained source of truth

Current pipeline:

    src/styles/tokens.css  --scripts/token-export-1.5.cjs-->  tokens 1.5/
                                                              (flat / DTCG / Tokens Studio)

Frozen at the state of tokens.css as of the commit that moved them here.
